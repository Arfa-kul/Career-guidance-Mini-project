# Local Development

## Prerequisites
- Node.js 18+
- PNPM, NPM, or Bun

## Setup
1. Copy .env.example to .env and fill values
2. Install deps: 
npm i (or pnpm i / bun i)
3. Start dev server: 
npm run dev

## Scripts
- npm run dev: Start Vite dev server
- npm run build: Build for production
- npm run preview: Preview build
- npm run lint: Lint code

## Tech Stack
Vite + React + TypeScript + Tailwind + Radix UI + shadcn/ui + React Router + Supabase (optional)
